## 🛠️ Состав библиотеки и бинарников

Ниже представлен список базовых утилит, которые входят (или планируются) в данный набор.

### 📝 Работа с текстом и выводом
* **`cat`** — Чтение файлов и вывод их контента в стандартный поток (stdout). Поддерживает склеивание нескольких файлов.
* **`echo`** — Простой вывод переданной строки текста или переменных окружения в терминал.
* **`head`** — Вывод начальных строк файла (по умолчанию первых 10) для быстрого просмотра.
* **`tail`** — Вывод финальных строк файла. Незаменим для мониторинга логов в реальном времени.
* **`grep`** - Мощный поиск строк по текстовым шаблонам и регулярным выражениям.
* **`wc`** — Подсчет количества строк, слов, символов и байт в указанных источниках.

###   Управление файловой системой
* **`ls`** — Просмотр содержимого директорий, отображение скрытых файлов и подробной информации (права, размер, дата).
* **`cp`** — Копирование файлов и целых папок с сохранением структуры.
* **`mv`** — Перемещение или переименование объектов в файловой системе.
* **`rm`** — Удаление файлов или директорий (включая рекурсивное удаление).
* **`touch`** — Создание пустых файлов или обновление временных меток (timestamp) уже существующих.
* **`mkdir`** — Создание новых каталогов (включая вложенные структуры путей).
* **`rmdir`** — Безопасное удаление пустых директорий.

### 🔒 Права доступа и окружение
* **`pwd`** — Вывод абсолютного пути текущей рабочей директории.
* **`chmod`** — Изменение прав доступа к файлам и папкам (чтение, запись, исполнение).
* **`chown`** — Смена владельца и группы для выбранных объектов системы.

---

## 🚀 Как это работает (Кратко)

Каждая утилита компилируется в отдельный независимый **бинарный файл**. Вы можете использовать их как самостоятельно в терминале, так и подключать общую внутреннюю библиотеку функций для кастомных скриптов.

Проект разработан с упором на скорость, минималистичность и максимальное соответствие стандартам POSIX.
